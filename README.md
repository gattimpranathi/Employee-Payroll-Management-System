# Employee Payroll Management System
Project Description
Employee Payroll Management System is a Java-based application used to manage employee details, attendance, salary calculations, and salary slips.

Features
- Admin Login
- Add and View Employees
- Attendance Management
- Salary Calculation
- Generate Salary Slips
- View and Print Salary Slips
- Payroll History
- Dashboard

Technologies Used
- Java 21
- JavaFX
- Maven
- PDFBox
- CSS
- CSV File Handling

Requirements
- Java JDK 21
- Maven
- Eclipse IDE

How to Run
1. Clone the repository.
2. Open the project in Eclipse.
3. Wait for Maven dependencies to download.
4. Run the command:

```bash
mvn clean javafx:run
```
